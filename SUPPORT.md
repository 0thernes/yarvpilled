# Getting help

- **How do I ...? / Why does ...?** Check the [FAQ](docs/faq.md) and the
  [architecture notes](docs/architecture.md) first, then ask in
  [Discussions](https://github.com/0thernes/yarvpilled/discussions).
- **Something is broken:** open a [bug report](https://github.com/0thernes/yarvpilled/issues/new/choose)
  and include the output of `ruby yarv_brain.rb --version`.
- **Idea for a new mechanic or experiment:** open a feature request.
- **Security issue:** see [SECURITY.md](SECURITY.md). Please don't use public issues for these.

This is a hobby project maintained in spare time, so responses are best-effort.
